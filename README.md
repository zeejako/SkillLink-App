# SkillLink
Location-based mobile app to find and book local service providers in East London. Built with Flutter + Firebase.

## Features
- Register/Login as Client or Provider
- Search, filter by category, sort by Top Rated / Nearest
- GPS + distance in km, Map View (teal dot = you, orange pins = providers)
- Book Now -> PENDING -> APPROVED -> COMPLETED -> RATED
- Provider Leads: Accept / Decline with instant notification
- Rating: 1-5 stars + comment, average auto-calculated e.g. 4.5 (2 reviews)
- Dark Mode, Edit Profile, Refresh Location

## How to Run
flutter pub get
flutter run
